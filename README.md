# Roblox (LARP)

A fan-made Roblox-style profile and avatar-shop simulator for Android. It is not affiliated with, endorsed by, or connected to Roblox Corporation.

## Features
- Roblox-inspired mobile navigation: Discover, Avatar, Shop, Profile.
- Local profile statistics editor (Robux, followers, following, friends, visits).
- Virtual Robux wallet and local accessory purchases/inventory.
- No Roblox login, account access, real-money purchases, or changes to real Roblox data.

## Build
GitHub Actions builds a debug APK on every push to `main`. Download it from the workflow run's Artifacts section.
